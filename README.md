# miniature-octo-waffle
Chess written in lua for LOVE2D.
> WIP

### Features:
```
Basic Turn Based setup,
Space selection onClick and deselection onRelease of a previously selected space,
Possible move highlights for the selected piece,
Drag-and-Drop moves,
```

### Missing:
```
Timers,
Check and Check Mate,
Preventing moves that leave one's King in check,

Pawns: Promotion
Kings: Castling
```
